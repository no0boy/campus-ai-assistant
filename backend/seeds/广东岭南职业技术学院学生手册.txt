广东岭南职业技术学院 - 学生手册（2025年版）

========================================
一、学校概况
========================================

广东岭南职业技术学院是经广东省人民政府批准、教育部备案的全日制普通高等职业院校，院校代码12749。

【校区地址】
- 广州校区：广州市天河区大观中路492号（邮编：510663）
- 清远校区：清远市清城区东城街道大学东路8号，省职教大学城内（邮编：511500）

【联系方式】
- 招生咨询：广州校区 020-22305555，清远校区 0763-3918555
- 学校官网：www.lnc.edu.cn
- 学校官方微信公众号：广东岭南职业技术学院

【校训】
明德、笃学、砺能、自强

========================================
二、专业设置
========================================

学校共开设47个专业，覆盖以下大类：
- 医药类：药学、中药学、护理、康复治疗技术、医学检验技术
- 信息技术类：软件技术、计算机网络技术、动漫制作技术、大数据技术
- 商科类：电子商务、商务英语、市场营销、现代物流管理
- 制造类：模具设计与制造、工业机器人技术、机电一体化技术
- 艺术设计类：环境艺术设计、视觉传达设计、数字媒体艺术设计
- 财经类：大数据与会计、金融服务与管理

【三二分段专升本】
学校与广州华立学院、广州理工学院、广州科技职业技术大学等本科高校合作，开展"3+2"专升本协同育人项目。学生在岭南就读3年专科后，通过转段考试进入合作本科院校再读2年，获得全日制本科文凭。

========================================
三、学籍管理规定
========================================

【学制与修业年限】
- 标准学制：3年
- 最长修业年限：6年（含休学、保留学籍时间）
- 每学年分两个学期，第一学期9月至次年1月，第二学期2月至7月

【课程与学分】
- 学生毕业需修满专业人才培养方案规定的全部学分（一般130-140学分）
- 课程分为必修课和选修课，选修课至少修满12学分
- 公共必修课包括：思政课、大学英语、计算机应用基础、体育等

【考勤管理】
- 学生必须按时参加教学计划规定的课程和各项活动
- 无故缺课累计超过课程总学时1/3者，取消该课程考试资格
- 因故不能上课需提前向辅导员办理请假手续

【缓考与补考】
- 期末考试时间为每学期最后两周
- 因病或其他特殊原因不能参加考试的，需在考前申请缓考
- 期末考试不及格的学生，可在下学期开学前一周参加补考
- 补考仍不及格的，需重修该课程
- 补考成绩最高按60分（及格）记载

【学业预警】
- 一学期有3门及以上课程不及格者，给予学业预警
- 连续两个学期学业预警者，给予退学警告
- 学生有下列情况之一者，予以退学：
  1. 连续两次退学警告
  2. 超过最长修业年限
  3. 休学期满未按时复学
  4. 未经批准连续两周未参加教学活动

【毕业条件】
- 修完人才培养方案规定的全部课程并取得规定学分
- 取得相应的职业技能证书
- 完成毕业实习和毕业设计（论文）
- 无未解除的纪律处分

========================================
四、奖助学金体系
========================================

【国家奖学金】
- 金额：8000元/年
- 条件：学习成绩排名前10%，综合测评排名前10%，无不及格科目
- 申请时间：每年9月-10月

【国家励志奖学金】
- 金额：5000元/年
- 条件：家庭经济困难（已通过贫困认定），学习成绩排名前30%，无不及格科目
- 申请时间：每年9月-10月

【国家助学金】
- 金额：2000-4500元/年（按困难等级分档）
- 条件：家庭经济困难学生，通过广东省家庭经济困难认定
- 申请材料：家庭经济困难认定申请表、相关证明材料

【校内奖学金】
- 一等奖学金：2000元/年（综合测评前3%）
- 二等奖学金：1000元/年（综合测评前8%）
- 三等奖学金：500元/年（综合测评前15%）

【国家助学贷款】
- 生源地信用助学贷款，最高12000元/年
- 在校期间由国家全额贴息
- 毕业后开始还款，最长还款期限20年

【勤工助学】
- 学校设有校内勤工助学岗位，优先安排家庭经济困难学生
- 薪酬标准：不低于广州市小时最低工资标准（约20元/小时）
- 每月工作时间不超过40小时

========================================
五、宿舍管理规定
========================================

【宿舍配置】
- 标准四人间或六人间，配备空调、独立卫生间、热水器
- 每层楼配有公共洗衣房（扫码付费使用）
- 宿舍区覆盖校园网WiFi

【作息时间】
- 宿舍开门时间：6:00
- 宿舍关门时间：周日至周四 23:00，周五、周六 23:30
- 熄灯时间：周日-周四 23:00，周五-周六 23:30（仅关大灯，插座不断电）

【访客管理】
- 异性访客不得进入宿舍楼
- 同性访客需在宿管处登记，并在22:00前离开

【违章电器】
- 严禁使用电热毯、电饭锅、电磁炉、电热水壶等大功率电器（超过800W）
- 严禁私拉电线、改装电路
- 查到违章电器者，给予警告及以上处分，没收电器

【宿舍调换】
- 确有特殊情况需要调换宿舍的，向辅导员提交书面申请
- 经二级学院审批后，报学生处统一安排
- 未经批准擅自调换宿舍的，予以通报批评

【退宿与走读】
- 原则上要求学生统一住宿
- 家庭住址在学校附近（步行15分钟以内）的可申请走读
- 走读需家长签署知情同意书，经审批后方可

========================================
六、军训安排
========================================

【军训时间】
- 新生军训安排在入学后第一学期开始前
- 通常为14天（包含理论学习2天+实操训练12天）
- 军训地点：学校操场及训练场地

【军训内容】
- 队列训练：立正、稍息、跨立、齐步、正步
- 体能训练：晨跑、俯卧撑、仰卧起坐
- 内务整理：叠被子、物品摆放规范
- 国防教育：军事理论课、国家安全教育
- 战术基础：匍匐前进、战场救护（部分营队）

【军训要求】
- 全体新生必须参加军训，计1个必修学分
- 统一穿着军训服装（由学校免费配发）
- 严格遵守作息时间，迟到早退者予以相应扣分

【军训请假与免训】
- 因身体原因不能参加军训的，需提供二级甲等以上医院诊断证明
- 免训学生需到场观摩，完成理论部分学习
- 因事请假需经辅导员和教官双重批准
- 请假超过3天者，需随下一级新生补训

【防晒与防中暑】
- 军训期间学校提供饮用水和防暑药品
- 如有不适立即报告教官，到阴凉处休息
- 建议学生自备防晒用品

========================================
七、图书馆使用规定
========================================

【开放时间】
- 周一至周五：8:00 - 22:00
- 周六、周日：9:00 - 21:00
- 法定节假日闭馆（考试周期间另行通知）

【借阅规则】
- 学生凭校园卡借书，每人最多借阅8本
- 借阅期限30天，可续借一次（30天）
- 逾期未还：0.1元/天/册

【自习室】
- 图书馆设有自习区域，需保持安静
- 禁止占座，离开超过30分钟视为放弃座位
- 考试周期间延长开馆至23:00

========================================
八、社团与活动
========================================

【社团注册】
- 成立新社团需向校团委提交申请，材料包括：社团章程、指导老师信息、发起人名单（5人以上）
- 审批通过后获得社团资格证，方可开展活动

【活动申请】
- 举办活动需提前两周向所在二级学院提交活动方案
- 大型活动（200人以上）需经学生处和安全保卫处批准
- 涉及收费的活动需额外报财务处备案

【志愿者服务】
- 学校鼓励学生参加志愿服务活动
- 每学年志愿服务时长纳入综合素质测评
- 优秀志愿者可获校级"优秀志愿者"表彰

========================================
九、违纪处分
========================================

【处分等级】
- 通报批评 → 警告 → 严重警告 → 记过 → 留校察看 → 开除学籍

【常见违纪及处分】
- 考试作弊：视情节给予记过至开除学籍处分
- 旷课累计：10节通报批评，20节警告，40节严重警告，60节留校察看
- 宿舍使用违章电器：警告及以上处分
- 打架斗殴：视情节给予记过至开除学籍处分
- 盗窃他人财物：给予记过至开除学籍处分

【申诉】
- 学生对处分决定有异议的，可在收到决定书后5个工作日内向学生申诉处理委员会提出书面申诉
- 申诉委员会在15个工作日内作出复查决定

========================================
十、学费与缴费
========================================

【收费标准（2025年）】
- 普通类专业学费：19000-20800元/学年
- 护理（中外合作办学）：23500元/学年
- 中外学分互认专业：27800-30800元/学年
- 创新精英班专业：29800元/学年
- 住宿费：2300-3600元/学年

【缴费方式】
- 学校统一通过银行代扣缴费
- 新生收到录取通知书后，按指引将学费存入指定银行卡
- 老生每学年开学前完成缴费

【退费规定】
- 开学前申请退学，全额退还
- 开学后一个月内申请退学，退还80%
- 开学后超过一个学期，不予退还当学期学费

========================================
十一、就业指导与实习
========================================

【顶岗实习】
- 第三学年（第六学期）安排顶岗实习
- 实习时长不少于6个月
- 实习成绩考核：企业评价（60%）+ 实习报告（20%）+ 校内指导老师评价（20%）

【就业服务】
- 学校就业指导中心提供职业规划咨询和就业推荐
- 每年举办春、秋两季校园招聘会
- 毕业生就业率连续多年保持在95%以上

========================================
十二、校园服务
========================================

【校园卡】
- 校园卡用于食堂消费、图书借阅、门禁通行
- 充值方式：微信充值、食堂人工窗口
- 丢失需立即挂失并补办（补办费15元）

【医务室】
- 广州校区：综合楼1楼，24小时值班
- 清远校区：学生宿舍楼旁，24小时值班
- 学生凭校园卡就诊，挂号费2元

【心理咨询】
- 学校心理健康教育与咨询中心提供免费心理咨询
- 预约方式：电话预约、微信预约、现场预约
- 严格保密，保护学生隐私

【快递驿站】
- 广州校区：学生宿舍区菜鸟驿站
- 清远校区：实训楼北侧菜鸟驿站
- 取件需出示取件码和校园卡
- 驿站开放时间：9:00-20:00
